An Image from next/image with the fill prop and no sizes.

Why is this an issue?

With fill the image takes the size of its parent, which Next.js cannot know. Without sizes the browser assumes the image is as wide as the viewport (100vw) and downloads the largest candidate of the srcset, even for a thumbnail in a grid: slower pages and wasted bandwidth, mostly on mobile.

The rule stays silent when it cannot see all the props: a spread such as {...props}, or a computed fill={value}.

How to fix it

Set sizes to the width the image takes at each breakpoint.

Noncompliant code example

import Image from 'next/image';

<div className="relative aspect-square w-1/3">
  <Image src={src} alt="" fill /> {/* Noncompliant */}
</div>

Compliant solution

import Image from 'next/image';

<div className="relative aspect-square w-1/3">
  <Image src={src} alt="" fill sizes="(max-width: 768px) 100vw, 33vw" />
</div>
