A "use client" module and everything it imports are bundled for the browser. This rule reports an import in a client module that brings server code into that bundle, directly or through modules without a directive:

  • a module that imports server-only;
  • a Node.js built-in the browser has no fallback for (fs, child_process, net, worker_threads..., with or without node:);
  • a database client (PrismaClient, drizzle drivers, pg, mysql2, mongodb, @vercel/postgres, kysely...);
  • in the imported module itself: Node.js crypto APIs such as createHmac or createCipheriv, or a read of a server environment variable whose name says it holds a secret or a database location.

Imports used for types only, require(), import() and imports of "use server" modules are not reported.

Why is this an issue?

Server code in the browser bundle either breaks the build ("Module not found: Can't resolve 'fs'", "This module cannot be imported from a Client Component module") or ships server logic, queries and the names of secrets to every visitor. The browser cannot open a database connection or read the server's environment, so the code cannot work there anyway.

Noncompliant code example

// lib/db.ts
import { Pool } from 'pg';
export const db = new Pool();

// components/Orders.tsx
'use client';
import { db } from '@/lib/db'; // Noncompliant: brings the database client "pg" into the browser bundle

export function Orders() {
  const [rows, setRows] = useState([]);
  useEffect(() => { db.query('select * from orders').then(r => setRows(r.rows)); }, []);
  return <List rows={rows} />;
}

Compliant solution

Read the data in a server component (or a Server Action) and pass it to the client component as props. Mark server modules with import 'server-only' so that such a mistake fails the build early.

// lib/db.ts
import 'server-only';
import { Pool } from 'pg';
export const db = new Pool();

// app/orders/page.tsx (server component)
import { db } from '@/lib/db';
import { Orders } from '@/components/Orders';

export default async function Page() {
  const { rows } = await db.query('select * from orders');
  return <Orders rows={rows} />;
}

// components/Orders.tsx
'use client';
export function Orders({ rows }) {
  return <List rows={rows} />;
}
