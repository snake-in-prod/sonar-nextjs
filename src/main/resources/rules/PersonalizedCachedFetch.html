Data that depends on the user should not go into a shared cache. This rule reports:

  • a fetch with cache: 'force-cache' or next: { revalidate } (other than 0) whose URL, headers or body use a value from cookies(), headers() or the session (auth(), getServerSession(), currentUser(), getSession(), getUser());
  • an unstable_cache callback that reads cookies, headers or the session, or uses such a value from the enclosing function without receiving it as an argument or listing it in the key parts;
  • a "use cache" function or file that reads cookies, headers or the session.

Why is this an issue?

The Next.js Data Cache and "use cache" entries are shared by every request. A response fetched with one user's token or for one user's id is stored on the server, kept across deployments of the same build, and can be served to another user when the key does not tell them apart. unstable_cache keys only on its key parts and arguments, so a value captured from the enclosing function leaks one user's result to everyone. Reading cookies or headers inside a cached scope fails at build or render time, or caches the first visitor's data.

The rule follows values through variables of the same function. It stays silent on options objects, helpers and cached functions defined elsewhere.

How to fix it

Do not cache per-user requests (cache: 'no-store'), or read cookies and the session outside the cached function and pass what the result depends on as an argument.

Noncompliant code example

const session = await auth();
const res = await fetch(`${API}/orders?user=${session.user.id}`, { next: { revalidate: 60 } }); // Noncompliant

const getPlan = unstable_cache(async () => db.plan.find({ where: { userId: session.user.id } }), ['plan']); // Noncompliant

async function getCart() {
  'use cache';
  const id = (await cookies()).get('cart')?.value; // Noncompliant
}

Compliant solution

const session = await auth();
const res = await fetch(`${API}/orders?user=${session.user.id}`, { cache: 'no-store' });

const getPlan = unstable_cache(async (userId) => db.plan.find({ where: { userId } }), ['plan']);
const plan = await getPlan(session.user.id);

async function getCart(id) {
  'use cache';
  return db.cart.find({ where: { id } });
}
