A redirect(), permanentRedirect() (next/navigation) or NextResponse.redirect() (next/server) whose target is taken from searchParams, params or form data, with no allow-list or same-origin check.

Why is this an issue?

An open redirect lets an attacker build a link on your trusted domain that sends the visitor to a site of their choice: https://your.app/login?next=https://evil.example. It is used for phishing, and to steal tokens when the redirect follows a sign-in. redirect() and NextResponse.redirect() accept absolute URLs, and new URL(value, request.url) keeps the host of an absolute or protocol-relative value.

The rule reports the target when it is the request value itself (a variable holding it, with a fallback such as ?? '/', a cast, String(), new URL(), or a template literal starting with it). It stays silent when the value is compared, tested (startsWith, match), passed to a check (isSafeUrl, allowed.includes) or transformed by a helper elsewhere in the function, and when a fixed path or origin comes first.

How to fix it

Accept only local paths (starting with one /, not // or /\), or compare the origin of the parsed URL with your own, or map the value to an allow-list.

Noncompliant code example

export default async function Login({ searchParams }) {
  const { next } = await searchParams;
  if (await auth()) {
    redirect(next ?? '/'); // Noncompliant
  }
}

export async function GET(request) {
  const to = request.nextUrl.searchParams.get('to') ?? '/';
  return NextResponse.redirect(new URL(to, request.url)); // Noncompliant
}

Compliant solution

export default async function Login({ searchParams }) {
  const { next } = await searchParams;
  if (await auth()) {
    redirect(next?.startsWith('/') && !next.startsWith('//') ? next : '/');
  }
}

export async function GET(request) {
  const url = new URL(request.nextUrl.searchParams.get('to') ?? '/', request.url);
  if (url.origin !== request.nextUrl.origin) {
    return NextResponse.redirect(new URL('/', request.url));
  }
  return NextResponse.redirect(url);
}
