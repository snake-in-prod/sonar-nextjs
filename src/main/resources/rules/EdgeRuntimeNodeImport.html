This rule reports imports in code that runs on the Edge runtime: a route handler, page, layout or other app/ file with export const runtime = 'edge', a Pages Router file with config = { runtime: 'edge' }, and middleware.ts unless its config sets runtime: 'nodejs'. An import is reported when it loads, directly or through project modules, a Node.js built-in the Edge runtime does not have (fs, child_process, net, tls, os, http, zlib, crypto... with or without node:), or a package that needs Node.js (bcrypt, argon2, pg, mysql2, mongoose, mongodb, sqlite3, better-sqlite3, nodemailer, sharp, ioredis, jsonwebtoken, firebase-admin, a PrismaClient created without a driver adapter or Accelerate). Type-only imports, require() and import() are not reported, nor the built-ins the Edge runtime provides (buffer, events, util, assert, async_hooks) and drivers with edge builds (@neondatabase/serverless, postgres, @libsql/client...).

Why is this an issue?

The Edge runtime offers Web APIs, not Node.js. A Node.js module it lacks fails the build, or is replaced by a stub that throws as soon as the code touches it: middleware that signs a cookie with createHmac rejects every request, a PrismaClient created when auth.ts loads crashes the middleware importing it.

Noncompliant code example

// middleware.ts
export { auth as middleware } from '@/auth'; // Noncompliant: auth.ts -> lib/db.ts creates a PrismaClient

// app/api/token/route.ts
import jwt from 'jsonwebtoken'; // Noncompliant

export const runtime = 'edge';

Compliant solution

Use edge-compatible code (Web Crypto, jose, an HTTP database driver or a Prisma driver adapter), keep the Node.js-only code out of what the edge file imports (an edge-safe auth.config.ts for Auth.js), or run the file on Node.js: remove runtime = 'edge', or set runtime: 'nodejs' in the middleware config (Next.js 15.5 and later).

// middleware.ts
import NextAuth from 'next-auth';
import authConfig from './auth.config'; // providers only, no adapter

export const { auth: middleware } = NextAuth(authConfig);
